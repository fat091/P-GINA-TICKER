# Página Ticker

Proyecto web desarrollado como práctica de desarrollo frontend utilizando HTML y CSS.

El sitio permite visualizar diferentes secciones relacionadas con eventos, consultar información, acceder a una sección de compra y utilizar un formulario de contacto.

## Funcionalidades

- Página principal
- Visualización de eventos
- Sección de compra
- Página de contacto
- Navegación entre diferentes páginas
- Diseño personalizado mediante CSS

## Tecnologías utilizadas
- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code

## Estructura del proyecto

```text
PROYECTO/
├── ProyectoFinal.html
├── comprar.html
├── contacto.html
├── eventos.html
├── styles.css
└── README.md
```

## Ejecución del proyecto

Para ejecutar el proyecto de manera local:

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `ProyectoFinal.html` en un navegador.
4. Opcionalmente, utilizar la extensión Live Server de Visual Studio Code.
